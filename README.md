# Abhijith M — Intune-style Infrastructure Dashboard

## Files
- `index.html` — website
- `style.css` — dashboard styling
- `profile.png` — supplied profile photo

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for deployment.

## Personalize before publishing
- Replace `YOUR-EMAIL@example.com` in `index.html`.
- Replace the GitHub URL with your real GitHub profile.
- Add `resume.pdf` to the root if you want a downloadable CV, then change `downloadResume()` to link to it.
- Add only certifications and metrics that are accurate and verified.

## Important privacy note
A private GitHub repository does NOT automatically mean a private GitHub Pages website. Depending on your GitHub plan/organization settings, Pages can still be publicly reachable. If the site must be accessible only to you or authorized people, use an access-controlled hosting option or GitHub Pages access controls available to your plan.
